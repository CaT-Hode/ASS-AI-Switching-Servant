# ASS v0.2.0

- 修复原生模型目录较大时的界面卡顿：同一轮状态读取共用配置解析结果，不再为每个模型重复扫描文件。
- 合并短时间内的状态推送，避免按钮操作、后台更新和状态请求反复重建同一份数据；窗口隐藏或最小化时暂停无用推送。
- 保留未变化的数据引用，减少额度刷新引起的用量图表与模型目录重复计算。
- 额度刷新与模型目录读取分离，取消额度更新时间触发自身再次刷新的循环；返回客户端页时不叠加状态请求。
- 账户资料分别处理成功、失败与缓存保存失败。查询失败保留上次成功结果，显示对应的超时、证书、代理或权限原因。
- 后台状态刷新异常只提示并保留当前画面，不中断已完成的操作；后续刷新可以恢复。
- OpenCode Go 查询权限不足不会再被自动限频结果误报为成功，也不会影响其他账户。Go 用量权限与模型调用权限分开处理。

不改动真实账户凭据，不自动重启 ASS 或正在运行的客户端。退出旧版后，重新打开 v0.2.0 生效。
