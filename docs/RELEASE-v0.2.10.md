# ASS v0.2.10

此次发布包含此前本地版本 v0.2.3–v0.2.9 的累计修改。

- 对话管理按项目聚合；横向胶囊仅显示本机已检测到的 Codex、Claude Code、DSH、OpenCode、pi。
- 每个项目独立同步开关，默认关闭。无项目会话只做内容管理；跨客户端标记“来自 xxx 的同步”。轮流续聊保留完成内容，分叉保留两支。
- 关闭项目同步后，将更新与分支另存回初始客户端，仅清理 ASS 创建的原生投影，原生历史不覆盖，清理副本可从本机备份恢复。
- Codex / CC 切换 OAuth 前增量加密保留本地对话；继续对话使用当前账户，不复制旧凭据。支持搜索、置顶、分页与缺失记录恢复。
- 账户卡片精简为账户名、订阅档位、额度 / 余额；同账户的原生与保存来源合并，不合并不同 API Key。支持显示明确返回的 Max 5× / 20× 等档位。
- 额度条移除端点白球：5h 蓝、周紫、月青绿，保留渐变与星光；账户、供应商和总览一致，动画在不可见时暂停。
- Codex / CC 注入与账户切换可选择强制关闭或重启；进程身份变化时不冒险关闭其他程序。
- Codex 使用 ASS 命名空间，旧命名空间不再作为兼容路由；保留官方与第三方请求的严格分流。Claude Desktop 模型使用稳定别名并保留展示名称。
- 主体内容上移，合并客户端刷新入口；移除供应商与客户端品牌图标动画，保留操作按钮反馈。
- 本地部署使用稳定的 `release/current` 与开始菜单入口，更新前检查运行中的 ASS，保留凭据与用户数据。

## 验证与边界

634 项自动测试通过；源码与发布版的项目同步、账户布局、订阅条和 OAuth 对话保留流程通过隔离 Electron 检查。Codex / CC 使用合成 OAuth 与本机模拟服务实际续聊；pi 原生读写、OpenCode 原生导入 / 导出 / 清理，以及 DSH v3 严格记录校验通过。

未使用用户真实凭据或外部付费推理，未关闭生产客户端。DSH 仍需在原生会话列表选择同步记录；本轮不宣称真实 DSH 模型推理已验证。跨格式同步保留文本历史与工具结果上下文，不迁移账户、权限或附件二进制；同卷优先硬链接，OpenCode 使用原生 CLI 导入。

Windows x64 便携包附 SHA-256。项目同步、历史备份及账户资料不包含在发布包中。使用前请退出旧 ASS，再从开始菜单打开新版。
