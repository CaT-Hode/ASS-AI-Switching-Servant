# ASS v0.3.4

- 项目会话同步：先持久化待发布记录，再写入原生会话副本。索引保存失败或进程中断后可在重启时恢复，重复同步不产生孤立副本；关闭同步或修改目标前先处理未完成事务，遇到外部修改时保留文件并报告冲突。
- 响应转换：Anthropic 因上下文窗口耗尽而截断的回答标记为未完成，流式响应与完整 JSON 响应一致，保留已有文本和用量。
- 历史界面：翻页失败后返回原页或重新选择同一条记录可重新加载正文，迟到的请求结果不会覆盖当前选择。
- Kimi：模型密钥为空或仅有空白时继承供应商密钥，显式非空模型密钥仍优先使用。
- DSH：识别当前及旧版运行记录，按实际 profile 读取与原生模型选择器相同的本地目录接口，不再使用固定默认模型或官方 `/models` 代替原生目录。目录不可读时仅显示显式本机配置；凭据、profile 或运行实例改变后旧目录失效。
- DSH 卡片：已归入供应商的同一凭据不再生成重复的空原生账户卡片；独立账户及未归入供应商的原生模型仍可见，不删除凭据或已有供应商模型。

## 验证

本机全量测试 **812/812 通过**。回归使用隔离假数据与本地模拟服务，包含索引保存失败、真实子进程中断、重复操作及真实 React renderer 的历史正文恢复测试。生产包检查确认 132 个运行文件与当前源码/构建产物一致，不含测试、QA 调试入口、开发依赖或用户数据。本机开始菜单安装已更新为 0.3.4 并确认进程启动。

本轮未执行真实 OAuth 登录、账户迁移、远端模型推理或 Windows 安装 EXE 的安装/卸载流程。DSH 本机实际目录在检查时不可读，线上模型数量对应关系需在 DSH 启动后进一步验证；发布不覆盖用户现有配置和历史数据。
