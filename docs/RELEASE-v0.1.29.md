# ASS v0.1.29

## 供应商配置与卡片

- “供应商与模型”新增导出配置。默认去除 API 密钥和额外请求头；可勾选包含密钥，先显示明文泄露风险，再选择保存位置。再次打开恢复安全默认值，取消不写文件。
- 导出只包含可移植的供应商与模型配置，支持重新导入。不包含 OAuth 令牌、客户端账户、协议检测缓存或本地路由凭据；不把真实密钥传回界面。
- 所有供应商卡片统一高度。有无余额、订阅额度、查询失败不改变卡片尺寸；较多额度明细可在卡片内滚动。
- Pi 客户端和原生目录改用 [Pi 官方单色 Badge](https://pi.dev/press-kit)，浅色模式黑色、深色模式白色；客户端图标缩小至 22px，居中且不改变点击区域。

## 接入等待与协议记忆

- 修复 CC 接入卡在“正在检查模型协议与接入状态”：接入、同步、修复弹窗不再等待整批模型联网检测，只使用已有观察结果。后台检测不会强行更新已应用的接入快照。
- 保存 / 新增模型时后台检测；已有检测结果长期保留，不再按 24 小时或 5 分钟过期。未知、拒绝、限流也不自动重复请求；手动闪电或连接身份变化才重新检查。
- 闪电同时检查连接与协议。模型行显示 Responses / Messages / Chat 的支持、不支持、未确认或未检测标记；检测时间与延迟可在提示中查看。订阅和原生账户不会被误当作通用 API 做多协议检查。
- 收到协议结束事件后立即结束检测，不再等待网关关闭流；请求与响应体有硬性等待上限，取消时释放读取器。超时不误判协议不支持。
- 新的 Codex 入口为 `/clients/ASS/v1`；旧 `/clients/codex/v1` 继续作为同权限别名兼容。同步后写入新地址，不因此关闭现有任务。

## 验证

- 454 项自动测试通过，覆盖导出脱敏 / 明文选项 / 重新导入、永久协议缓存、流式结束和超时，以及新旧入口的客户端边界。
- 隔离 Electron 窗口验证：深浅模式卡片等高、额度溢出滚动、导出警告和取消、Pi 官方标识、协议标记与重启后记忆；模拟上游永不返回时，CC 确认窗口仍可正常进入。
- Codex / CC 隔离接入测试通过：自动协议选择、无账号模式、重启后持久化，原 OAuth 保留。测试未关闭或重启用户正在运行的客户端。
- 本轮未重新消耗真实供应商推理额度；测试不保证上游权限、余额和服务可用性。未检测或未确认的协议保留原配置，用户可点闪电确认后同步接入。
