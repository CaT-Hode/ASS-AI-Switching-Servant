# ASS v0.1.24 · 接入修复、日夜主题与诊断记录

- 左栏新增等宽三档日月胶囊：浅色 / 自动 / 深色，中间清晨或黄昏表示跟随系统。每档都有轻微常驻动效：日光 / 云朵、晨昏呼吸光、星点 / 月光。点击轮换或拖拽吸附，动效跟随手势，月牙保持竖直；主题跨重启保存，不增加动画设置菜单。
- 侧栏及常用图标加入悬停 / 点击形变：四格散开收拢、诊断波形变化、设置滑块换位、删除盖子抬起、刷新旋转、上传下载箭头移动，以及文件夹、账户、密钥、余额、模型闪电等反馈。快速点击保留短暂回弹，连续操作不中断动作；不增加动效设置项。深色主题覆盖弹窗、图表、账户卡片与供应商 logo。
- 连接诊断保存最后一批进度和逐模型结果，重启不会清空。展示上次测试时间、响应头 / 首字延迟、总耗时、HTTP、流事件、返回数据量和上游实际提供的 token 用量；缺失值不补零，配置变化保留带失效标记的历史。
- 启动固定进入路由总览，其他选择与筛选继续保存。
- 七种客户端统一支持“接入异常 → 一键修复”：Codex、Claude Code、OpenCode、pi、DSH、Kimi Code、ZCode。按各客户端格式恢复上次已确认的受管配置或路由，不顺带同步草稿；先保存加密备份，不关闭客户端、不改官方登录。未知归属、损坏或无法解密的恢复记录、不可解析文件仍安全阻止并提示原因。
- 已验证的 DeepSeek、OpenCode Go / Zen 原生 API 凭据自动加入加密供应商目录，可在其他客户端的供应商接入开关中使用。原凭据不改写，已有供应商去重，不覆盖用户编辑或自动恢复主动删除的供应商。
- Claude 优先使用原生 Messages，DeepSeek 使用官方兼容入口；其他 Chat Completions / Responses 模型支持文本和函数工具适配，保留工具 ID、并行调用顺序与会话标识。不支持的多模态 / 服务端工具或精确 token 计数明确报错。

升级不自动同步正在运行的客户端配置。新供应商保存后，已开启的客户端接入需在“客户端与账户”确认同步；不改变官方账户归属，也不把 OAuth 当作通用 API Key。

退出旧版 ASS，完整解压 Windows x64 ZIP 后运行 `ASS.exe`。数据目录不变，无需重新导入已有配置。兼容性和计费最终以实际供应商权限为准；隔离测试不代表每个真实账户或全部 Agent 功能均通过实网验证。
