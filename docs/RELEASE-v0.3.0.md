# ASS v0.3.0

本次发布汇总 v0.2.17 之后的修改。

- “历史与存储”支持加密副本预览、占用统计、恢复、单项和按客户端清理，以及已删除备份的永久清理。归档、索引缺失、非当前副本和仅保留副本单独显示状态与读取来源；正常列表和自动同步排除这些残留记录。
- DSH 扫描根据手动目录、所选启动器、`DSH_HOME` 和便携安装解析数据位置。凭据、官方 API、接入配置和对话读取共用规则，支持目录移动、中文与空格路径及不同启动器，不依赖某台设备的路径。
- DSH 对话预览与新收集的共享历史保留真实用户输入和助手正文，过滤 system / developer 提示、自动注入上下文、思考、工具调用、工具结果和压缩摘要；修正旧标题缓存，保留 Markdown、代码和最终回答。
- 模型检测逐项检查 Responses、Anthropic Messages 和 Chat Completions，其他接口成功后仍测试 Chat；取消或限流时停止剩余探测。
- 修复模型设置编辑行在深浅色主题中的黑边，保留保存和取消操作。
- Logo 花瓣收窄、间距增大；中心环向内加粗，并略微扩大与花瓣的距离。SVG、PNG、ICO 与应用图标同步更新。
- 更新检查和下载入口使用当前仓库名称，正确识别 GitHub 返回的发布地址。

## 验证

710 项自动测试通过。Windows x64 发布包通过隔离 Electron 启动与 DSH 对话回归检查；123 个运行时文件与源码及构建产物一致，发布内容检查通过。DSH 回归覆盖旧缓存、刷新、重启、深浅色主题和 1380 / 1100 窗口宽度；原始测试日志逐字节保持一致。新增回归验证当前仓库发布、ZIP、校验文件的 URL 以及重启后的更新缓存。

界面验证使用合成账户与响应；本次未验证外部供应商的付费推理权限。旧共享库中已收集的正文不会自动改写。账户、凭据、用户对话和验证资料不包含在发布包中。

## 下载

Windows x64：`ASS-v0.3.0-win32-x64.zip`，校验文件：`SHA256SUMS.txt`。完整解压后运行 `ASS.exe`，保留同目录的资源与 DLL；使用前退出旧 ASS。
