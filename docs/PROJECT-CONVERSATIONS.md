# 项目级对话管理与同步

ASS 0.2.10：先用横向胶囊切换本机已识别且支持的 Codex / Claude Code / DSH / OpenCode / pi，再按项目聚合会话。项目按规范路径识别，不因名称相同合并；缺少项目目录、用户主目录及 Codex 自动生成的非项目工作目录归入“无项目会话”，不提供同步。

## 开关与内容归属

关闭状态仍可读取、预览、搜索及在原客户端继续，Codex/CC 的 OAuth 历史保留与置顶功能不受影响。只有打开项目右上角“项目同步”后才收集共享正文；可展开“同步客户端”调整参与范围。其他客户端视图及生成的原生记录显示“来自 xxx 的同步”。

切换顶部客户端后，选择项目内对话继续。ASS 在启动前收集已完成新内容，按需生成目标格式，采用当前客户端的凭据；不迁移 OAuth、API Key、插件、系统提示或工具许可。ASS 运行时每 15 秒检查已开启项目。轮流续聊可保持共同历史；并发分叉保留两支，不按时间戳拼接。已经运行的客户端内存上下文不会被在线替换。

关闭开关不是暂停：先收集完成内容及分支，在初始客户端内创建必要的归回记录，然后移除 ASS 生成的跨客户端副本。原始日志不覆盖，独立原生会话不删除。若 ASS 续聊窗口仍在运行、轮次未完成、来源身份或文件变化，清理会停止并保留同步状态。失败可重试，不宣称已经清理。

移除前的副本在 ASS 数据目录 `project-conversations/released`，归回快照在 `returned`，可手动恢复。关闭后清空该项目的共享图；重新开启从现存原生历史重新收集，不复活已移除副本。退出 ASS 不删除原生会话，也不等于关闭项目同步。

## 存储

统一库位于 ASS 数据目录的 `project-conversations`。索引与密钥由 Windows 加密存储保护，共享消息正文采用 AES-256-GCM、按内容哈希去重；重复内容和分支前缀只保存一份，各次时间独立记录。

Codex / CC / pi 的 JSONL 与 DSH 的 Zstandard JSONL 在同卷优先文件硬链接；跨卷或不支持链接时独占创建副本。原生原子替换断开链接后，不覆盖新文件。跨格式需要独立投影，不能把不同格式链接成同一个日志。没有目录级链接，也没有链接认证文件。

OpenCode 只读原生 SQLite，投影使用官方 `import`，关闭同步使用官方 `session delete`；不直接改写活动数据库。续聊、归回和清理需要可用 CLI，只安装桌面端仍可读取。CLI 不可用或清理失败时不会报告关闭成功。

## DSH / pi 适配边界

- DSH：读取已知 v0–v3 事件；兼容 v2/v3 的替换范围、嵌套工具结果及压缩日志。写入 v3，经官方严格恢复器验证。未知 v4+、损坏和未完成记录不强行转换，原始文件不迁移。当前 web profile 启动后仍需在 DSH 会话列表选择提示的会话 ID，尚未自动跳转。
- pi：v1 线性记录只在内存中规范化；v2/v3 按活动父链读取。系统提示、扩展授权和用量记录不误当助手消息同步；未完成工具轮次留在来源。原树分支仍在原日志。
- pi 支持 `PI_CODING_AGENT_SESSION_DIR` 自定义目录；续聊显式指定文件与会话目录。若当前 `settings.json` 配置了默认供应商/模型，启动采用它们而不是历史模型元数据。
- 新账户的模型权限仍由原生客户端决定。历史工具操作是不可执行的文本上下文，不会重放调用。附件实物仍在来源存储，跨格式只保留来源说明，不承诺附件/插件零损失迁移。

格式依据：[pi 会话格式](https://pi.dev/docs/latest/session-format)、[DSH 会话系统](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/session/README.md)、[OpenCode CLI](https://opencode.ai/docs/cli/)、[Claude Code 会话](https://code.claude.com/docs/en/sessions)。Codex 适配依据公开实现及本机隔离 CLI 验证；仅解析文件不等于原生续聊验证。
