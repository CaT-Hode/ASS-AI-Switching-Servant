# ASS v0.1.12

- 客户端接入开关移到右侧详情栏的状态行，左侧仅负责选择客户端。五种客户端仍各自保存接入状态，保留简短的确定 / 取消确认。
- 修复 Windows 已安装 OpenCode Desktop 却显示未安装：补充用户 / 系统桌面安装目录识别，兼容 Node 与 Electron 对 ASAR 文件的不同表现。
- 区分 OpenCode Desktop 与 CLI；仅检测到桌面版时显示“已安装桌面端”，提供打开桌面客户端的图标入口，不向桌面程序传入 CLI 授权或模型参数。
- 若同时存在 CLI 和桌面版，自动优先使用唯一 CLI，保留桌面打开入口；明确选择的客户端位置不会被自动覆盖。

## 验证与边界

- 148 项核心测试通过；真实隔离 Electron 窗口覆盖五种客户端切换、右栏开关、确认 / 取消、接入状态独立与重启恢复，以及 1100 / 1380 / 1536 横版桌面布局。
- 实机只读识别已有 OpenCode Desktop；没有重装 OpenCode、修改本机凭据或启动 / 中断用户任务。打开桌面客户端的 IPC 使用测试替身验证目标路径与行为，没有为测试启动真实桌面客户端。
- OpenCode Desktop 识别不等于 CLI 接入支持。仅安装桌面版时，ASS 的独立账户启动和路由接入仍需另行配置 OpenCode CLI；本版会显示原因，不冒充已接入。

## 升级

完整解压 Windows x64 ZIP 后启动 ASS.exe，继续使用原有 ASS 数据。若旧版仍在托盘运行，请先等任务结束，再退出旧版并打开新版。
