# OAuth 切换与本地对话保留

ASS 0.2.7 起为 Codex 与 Claude Code 提供独立的“对话管理”页。账户和历史使用不同的索引：切换 OAuth 不改变会话目录，也不按当前账户过滤本地历史。

## 切换时

1. 在“客户端与账户”选择已保存的 OAuth 账户。Codex / CC 提供“仅切换账户 / 强制关闭 / 强制重启”，每次默认仅切换账户。
2. 确认后先读取本机目录与 ASS 独立账户 / 模型窗口的 JSONL 会话，增量加密保存到 ASS 数据目录 `conversation-library`。密钥与索引由 Windows 加密存储保护，会话正文另用 AES-256-GCM 加密。不包含 `auth.json`、`.credentials.json`、API Key 或原生认证数据库。
3. 保存完成后才替换 OAuth 字段。无法读取、加密或保存时停止切换；保存期间登录信息变化时仍会拒绝旧确认，不覆盖新登录。
4. 不删除或重写原生会话、SQLite 线程索引、Claude 的项目 / 信任配置。成功切换后把 ASS 的启动账户选择对齐到原生凭据目录，避免又启动旧独立账户。

默认不强制结束任务。已运行的客户端可能缓存旧令牌，用户应先结束任务，再重开客户端；明确选择强制关闭时先关闭已验证的桌面 / ASS 托管窗口并中断该客户端路由请求，切换后不重新打开。强制重启在完成保留和切换后重新打开已确认的桌面入口；重启失败单独提示，不抹掉已保存历史。身份无法确认或 ASS 自身在目标进程树内时选项不可用。ASS 无法把一个执行中的请求无缝改到另一个账户。

## 查看与继续

- 历史只读汇总 Codex `sessions` / `archived_sessions` 和 CC `projects`，同时包含原生自定义目录与 ASS 独立窗口。相同客户端、相同 UUID 的多目录记录在列表中合并显示；子代理会话不混入主对话列表。
- Codex 原生 SQLite / `session_index.jsonl` 只用于补充标题，不是列出会话的唯一条件。索引暂时不可读不会抹掉已观察的 JSONL 历史。
- 置顶与保留索引跨 ASS 重启保存。每次只向界面传送 40 个会话及 40 条文本消息，不向全局状态广播完整正文；查看消息不触发推理请求。
- CLI 续聊使用当前客户端凭据目录与当前接入配置，回到原工作目录。不会把会话来源目录中的旧 OAuth、API Key 或设置复制过来。原项目缺失时可先在“客户端设置”选择可用工作目录。
- CC 使用其支持的绝对 JSONL 路径继续跨目录会话。Codex 使用 UUID；需要时把历史内容独占写入当前会话目录，不覆盖既有同名文件，不修改旧文件的模型 / 供应商字段。
- 原记录消失但存在已保留副本时，可解密恢复到当前会话目录后继续。恢复过程验证加密完整性，损坏副本不写入原生目录。
- Codex 桌面入口通过已注册的 `codex://threads/<uuid>` 打开，仅限桌面默认凭据目录；刚换 OAuth 后需自行重启桌面，不能假定运行中的窗口已读到新账户。

## 明确边界

- 保留的是已经在本机落盘的历史，不包含尚未同步的云端记录或未写盘的正在执行内容。
- 自动保留发生在 ASS 确认切换或启动原生登录 / 退出流程之前。首次通过其他软件切换并已经删除的记录，ASS 不能凭空找回；可以提前点“保留历史”。
- Claude Desktop 普通聊天、Cowork、网页和 CC CLI 的历史不是同一个库，本页不迁移云端聊天或跨组织权限。OAuth 权益、模型访问权限由官方客户端决定；保留历史不等于保证另一账户拥有相同模型权限。
- 原生 JSONL 格式是内部格式。未知行不执行；文本预览会忽略工具二进制 / 超大行，恢复保留完整的原文件内容。预览最多回看最近 2,000 条文本消息，早期正文仍在原会话或副本中。
- 新增功能不改写现有对话的内容、供应商标识和权限策略；不存在自动删历史或未经选择的关闭 / 重启。
