# ASS v0.3.2

- Logo 改为镂空花瓣与连续白色轮廓：消除花瓣描边间的细缝，统一加粗外围白边，保留橙色中央齿轮；同步更新 SVG、PNG、Windows ICO。
- 修复供应商删除保存失败后的内存回滚、`native-*` 普通供应商 ID 的模型目录误判，统一配置创建、导出、导入的数量与大小上限。
- 修复原生项目改名后的名称与搜索、同步关闭再开启的 retired 投影处理，以及新旧用量记录副本的选择顺序。
- 请求日志分别记录 HTTP 和模型任务结果，HTTP 200 的失败任务显示为任务失败。
- 修复自家 `resources/ass.ico` 的部署清理白名单、会话自动选择后的正文分页，以及恢复面板和模型默认值的迟到回复。
- 包含第二轮流式响应、OpenCode 同步恢复、Pi OAuth 并发锁、Kimi 模型路由等已完成修复，见 [第二轮修复记录](ROUND2-FIXES.md) 和 [可靠性修复记录](RELIABILITY-FIXES.md)。

## 验证

此前全量 771 项测试与最终相关 39 项检查通过，第 8、9 项已有 10 项真实 React renderer 测试。本次 Logo 相关 6 项检查、生产构建、运行产物审计及隔离生产包启动均通过。256px 图标的白色轮廓连通性检查确认花瓣白边连成一个整体。

131 个运行文件与源码/构建产物一致，263 个归档条目通过审计；生产包无 QA 调试入口、测试文件或用户数据，隔离启动未产生页面错误。CI 补齐 Electron 运行时安装与 Linux 虚拟显示，测试环境的 Linux 沙箱选项不进入生产包。

验证仅使用隔离数据和本地模拟响应，未使用真实账户、远端模型或真实历史进行端到端验证；本轮未升级本机安装或清理实际旧版本。
