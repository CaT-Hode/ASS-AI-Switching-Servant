# ASS v0.1.3 · 接入各自独立，关闭先看影响

模型随你切，账户由你管。本版保留 v0.1.2 自动检查更新，并将接入与服务控制统一放在客户端页面。

## 变化

- 删除全局“接入 Codex”，Codex / Claude Code / OpenCode / pi / DeepSeek Harness 各自提供 ASS 接入开关。
- 两层菜单：选择安全断开或结束 ASS 窗口，再核对配置、进程和其他客户端的影响；默认取消，不自动重启 harness。
- 有进行中请求时拒绝断开；请求数为零不代表任务结束，需用户确认工具和会话已结束。
- 按客户端隔离接口。关闭其中一个不会停其他客户端；最后一个接入关闭才停止共享服务，全部关闭状态跨重启保留。
- 记录并恢复 ASS 注入文件，保留凭据、会话和项目；外部改动会阻止覆盖。仅关闭通过 PID、创建时间、随机标记及父子关系校验的 ASS 窗口。
- 托盘“安全退出”也使用同一确认流程。

## 安全边界

Codex App、手动启动和旧版未登记窗口需要用户自行退出；不会按进程名批量结束。原生 OAuth 直连模式与路由注入分开；主动脱离进程树的后台服务不在自动终止保证范围内。部分终止或配置冲突会明确报错，不伪装成全部成功。

## 升级

等待当前任务结束，从旧版托盘退出 ASS，完整解压 ZIP 并运行新版 ASS.exe。账户数据仍使用 `%APPDATA%\AI Switch Servant`，无需重新导入。旧快捷方式需指向新版目录。此版本是未签名 Windows x64 预览版，请核对 SHA256SUMS.txt。
