# ASS v0.1.17

账户管理与模型接入分离。

- Codex 仅添加 OpenAI，Claude 仅添加 Anthropic，DSH 仅添加 DeepSeek API，OpenCode 仅添加 Go / Zen API；pi 保留本机支持的 OAuth 与兼容授权导入。前后端共同校验，不再通过“协议兼容”把其他供应商当作官方账户。
- 接入范围独立于账户卡片，默认所有已配置、启用且兼容的 API 模型；可排除模型、设置默认值、直接启动模型。移除账户卡片不撤回模型注入。
- 保存仅更新草稿，确认同步后应用；重启不自动刷新已应用的模型目录或原生配置。Codex / Claude 的已应用路由与恢复事务使用 DPAPI 加密保存。
- API 账户无需配置模型或开启接入即可启动。新账户窗口继承上次应用的模型字段；账户选择只对下次启动生效，不声称切换已有窗口。
- 保留 Codex OAuth；本地 API 模型窗口不展示订阅回退模型，本地路由令牌不能访问订阅端点。Claude 官方账户启动检查密钥 / 端点覆盖项，避免静默使用其他计费身份。
- 修复 pi 自定义模型目录缺少必填认证声明导致整组模型无法加载；修复 DSH 使用不存在的 `tui` profile，改用已验证的 `web` 配置与单次启动覆盖文件。
- 一次性迁移旧绑定并保留备份；不符合归属的账户卡片被隐藏，供应商、密钥、模型和原生 OAuth 保留。损坏或较新版本的账户配置拒绝覆盖。

## 升级

等待任务结束，退出旧版 ASS，完整解压新版后运行 ASS.exe。数据目录不变，无需重新导入 API。升级不会自动改写生产客户端配置；旧接入出现“待同步”时，请在客户端任务结束后手动确认同步。

配置可读性已通过 pi 0.73.1、OpenCode 1.18.31、本机 DSH 0.1.5-rc.1 原生读取器验证；未发送付费模型请求，未重启生产客户端。完整验证范围见 [验证记录](https://github.com/CaT-Hode/ASS-AI-Switching-Servant/blob/main/docs/VALIDATION.md)。
