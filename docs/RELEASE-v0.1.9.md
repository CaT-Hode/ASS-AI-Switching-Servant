# ASS v0.1.9

- 供应商与模型改为三级界面：供应商卡片、模型列表弹窗、右侧模型详细设置弹窗，不再在同一页堆叠。
- 一级卡片汇总模型数量、协议、上下文配置和余额；点击卡片进入对应供应商。
- 二级列表保留五项行内编辑、启用 / 停用、添加 / 删除、模型发现和逐模型闪电检查；每行直接提供“详细设置”入口。
- 三级弹窗出现在二级右侧，二级同步左移、收窄让位，保持间隔且各自滚动。关闭三级后二级恢复居中宽度与原按钮焦点；Escape 每次只关闭最上层。
- 模型设置、模型发现、能力详情及供应商设置使用同一套右侧面板；桌面窄窗口下左侧字段换行，减少动态效果模式不做位移动画。
- 返回卡片页保留搜索条件、滚动位置与当前页面会话的未保存草稿；侧栏入口回到供应商卡片，客户端与总览中的“查看 / 管理模型”直达对应列表。
- 原生只读模型目录使用相同分层。仅进入供应商详情时自动读取其模型目录，卡片页不自动发起目录请求。

## 升级

数据目录仍为 `%APPDATA%\AI Switch Servant`，无需重新导入。等待客户端任务结束后，从旧版托盘安全退出再打开新版。不会自动重启 ASS 或正在运行的 harness。

ZIP 为未签名 Windows x64 便携版，请完整解压并核对 SHA256SUMS.txt。验证范围见 [VALIDATION.md](VALIDATION.md)。
