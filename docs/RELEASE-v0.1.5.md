# ASS v0.1.5 · 客户端账户卡片

- Codex、Claude Code、OpenCode、Pi、DeepSeek Harness 独立检测本机 OAuth / API 凭据，修复现有 ChatGPT OAuth 不出现在客户端账户中的问题。
- 登录状态集中在客户端页右侧卡片；OpenCode、Pi、DSH 按供应商分别展示。支持默认、环境变量与自选凭据目录，过期与未知状态明确标注。
- 五种客户端左侧各有接入胶囊，沿用简短警告与确定 / 取消；不自动中断或重启正在运行的客户端。
- 选中供应商自动读取模型目录，可搜索并一键加入；并发请求去重，缓存隔离，凭据变化后失效。
- 持久保存账户 / 模型选择、凭据目录和页面选择；保留既有模型、余额、入口、接入与更新配置。登录状态重新读取，不持久缓存为“已登录”。
- 删除空泛说明、重复状态和口号，账户卡片直接提供选择、登录 / 退出、模型与启动操作。

102 项测试、生产构建及隔离 Electron 桌面交互 / 重启恢复检查通过。真实本机只读确认 Codex OAuth 识别；未替用户进行 OAuth 登录、刷新或联网验证。

## 升级

等待当前任务结束，从旧版托盘退出 ASS，再运行完整解压的新版 `ASS.exe`。数据仍使用 `%APPDATA%\AI Switch Servant`，无需重新导入。经 ASS 路由的客户端需重新启动以取得新的本地令牌。

本地凭据检测不等于远端有效性验证；Codex keyring / 临时存储及未知凭据类型交由原生客户端确认。OpenCode / DSH 本机多供应商账户仍在原生界面选择具体供应商。此版本是未签名 Windows x64 预览版，请核对 SHA256SUMS.txt。
