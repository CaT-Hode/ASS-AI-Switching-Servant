- DSH / OpenCode / pi 改为原生 API 直连：按字段管理供应商、模型和 API 凭据，保留已有 OAuth 与无关配置；退出 ASS 保留直连，主动关闭开关才撤回。冲突提示、重试和加密恢复记录齐备。Codex / Claude Code 的接入方式不变。
- 供应商卡片精简为名称、类型、模型数和可查询额度；自动匹配 21 类本地品牌 logo，未知供应商保留文字头像。
- 卡片右上角手柄支持拖拽与方向键排序，重启后保留；Esc 取消，筛选时不移动隐藏来源，保存失败不丢失原顺序。
- OpenAI / Anthropic OAuth 显示实际窗口的剩余额度，DeepSeek 等 API 显示原币种余额。可选择展示额度的账户，不切换客户端登录；只读自动 / 手动刷新，失败保留带时间的上次结果。
- 模型连接测试结果与完整时间加密持久化，显示“几分钟前 / 小时前”，悬停查看完整日期。成功 / 失败实心闪电跨重启保留，未测试仍为空心；取消不覆盖旧记录，连接参数变更使对应记录失效。

## 升级

完整解压 Windows x64 ZIP 后启动 ASS.exe，继续使用原有 ASS 数据。若旧版仍在托盘运行，请等待任务结束后退出旧版，再打开新版。不要在运行任务期间强制重启客户端。

DSH / OpenCode / pi 的旧接入请在任务结束后点击客户端页的同步图标确认迁移。原生凭据文件会保存真实 API Key，不是 DPAPI 密文；请勿分享。原生网络 / CA 由各客户端运行时负责，详见 [原生 API 接入](https://github.com/CaT-Hode/ASS-AI-Switching-Servant/blob/main/docs/NATIVE-CONFIG.md)。
