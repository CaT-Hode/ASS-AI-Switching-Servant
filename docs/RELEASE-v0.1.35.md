# ASS v0.1.35

- 原生 API 去重：DSH / OpenCode / pi / Kimi / ZCode 仅排除当前生效的相同 API；其他 Key、接口和租户请求头保留。
- 从七种客户端的已知配置来源聚合 API。没有模型列表时也可发现供应商，之后通过供应商模型目录补齐。
- OpenCode 支持所选项目、内联与托管配置的层级合并；pi 支持原生认证优先级和环境变量引用。
- 修复 DeepSeek 根地址识别；统一供应商归并和注入去重规则。
- 保留用户对供应商及模型的编辑、删除与排序，不循环导入 ASS 注入项。
- 本版本不会自动重启 harness 或自动改写其接入配置。已有重复注入可在客户端页确认同步后撤回，原生账户保留。

配置边界与来源见 [原生 API 接入](NATIVE-CONFIG.md)。
