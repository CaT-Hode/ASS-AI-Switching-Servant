# ASS v0.2.1

- 修复 Claude 网关发现遗漏非 Claude 名称的模型：Messages 原生、Responses 转换、Chat 转换统一出现在模型目录；本地发现别名会还原为供应商的原始模型 ID，不冒充上游模型。
- Claude 无账号开关默认同时配置终端和桌面版。两端写入纳入同一加密事务，冲突或写入失败不会留下只完成一半的开启状态。
- 移除独立的桌面版接入开关，提供桌面启动入口和精简的 Continue with Gateway 提示。已有终端免登录配置点击一次同步即可补齐桌面版。
- 补齐 Microsoft Store 和用户目录安装的 Claude 桌面版识别，将桌面程序与 Claude Code 命令行启动入口分开。
- 保持直接退出保留配置、安全退出撤回配置的行为。不自动关闭或重启正在运行的客户端。
- 供应商配置在状态刷新时重新读取，外部迁移后不会一直显示旧列表；保存前检测并阻止旧内存覆盖新文件。
- 按具体 API 身份排除的原生供应商不会再从原生模型目录重新出现，原生账户与其他 Key 不受影响。

网关发现筛选行为参考 [Claude Code 官方文档](https://code.claude.com/docs/en/llm-gateway-protocol#model-discovery)。协议转换不代表所有上游都支持 Claude 的完整工具、图像及扩展能力；实际支持情况仍以模型测试为准。
