# ASS v0.1.2 · 让模型切换更顺手

模型随你切，账户由你管。这个版本为 ASS 加入自动检查更新，并将桌面窗口、托盘、侧栏和产品介绍统一为以 ASS 为主的品牌表达。

## 新增

- “关于 ASS”更新页：查看当前版本、最近检查时间、新版说明、Windows 下载和 SHA-256。
- 启动约 10 秒后按需检查，此后每 6 小时检查；跨重启缓存、ETag、重复请求合并、15 秒超时和限流退避。
- 自动检查开关、预览版本开关、手动检查、可收起的新版本提示；侧栏和托盘均可进入检查。
- 只查询本仓库的公开 Release，不携带模型凭据、不上传账户信息。自动检查失败不影响路由请求。

## 更新方式

完整解压 ZIP，运行 ASS.exe。现有账户仍使用 `%APPDATA%\AI Switch Servant`，不改名、不迁移、不重新导入。

本次是“自动检查”，不是“静默安装”：点击下载后由浏览器下载，先核对 SHA256SUMS.txt，待请求结束后从托盘退出旧版再运行新版。旧快捷方式需指向新版目录。此版本仍是未签名预览版。

既有官方账户中心、DSH 自动识别、逐模型闪电与能力检测保留；Cursor / Kimi 原生 OAuth 和 Codex 跨协议工具的边界保持不变，见 README。
