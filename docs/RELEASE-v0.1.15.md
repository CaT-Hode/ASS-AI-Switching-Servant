## 升级与边界

完整解压 ZIP 后打开 ASS.exe，使用原有 ASS 数据。若旧版仍在托盘，请等待任务结束后退出旧版再启动新版；不要强制结束客户端任务。

本地用量不是供应商账单。DSH 当前读取 cost-meter 已有日账本，没有该文件则显示无记录；其他设备及被删除的历史不在范围内。统计不猜测历史请求的登录账户。没有重新验证所有供应商的实网模型连接。

DSH 接入按绑定的 API 供应商写入，不会自动注入全部供应商。在客户端与账户 → DSH → 添加账户中绑定已有供应商，并配置启用模型后同步。单独开启开关但没有绑定任何可用模型，不会生成第三方目录。本版不擅自绑定供应商或重启正在运行的客户端。

详见[用量来源与口径](https://github.com/CaT-Hode/ASS-AI-Switching-Servant/blob/main/docs/USAGE-OVERVIEW.md)。
