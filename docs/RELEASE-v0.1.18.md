# ASS v0.1.18

重整「客户端与账户」：左侧选客户端，右侧独立管理供应商接入和官方账户。

- 接入总开关固定在右上角；供应商按整组开关，展开查看兼容模型。删除逐模型勾选、默认模型和“启动模型”，在原生客户端选模型。
- 已识别客户端优先，其他客户端折叠；安装路径、凭据目录收进设置。路由总览只显示有本机识别证据的客户端、账户与统计。
- 账户卡片自然高度显示身份、套餐和已获取的额度。修复客户端卡片漏读独立订阅用量缓存：OpenAI / Claude 已查询的额度、错误和刷新入口正确保留，不相加百分比。
- 缩短开关、展开和按压反馈；键盘操作不播放动画，支持减少动态效果、减少透明度和高对比度。保持横版桌面布局。
- 接入偏好持久化。旧模型排除项安全迁移为供应商关闭并备份；升级不自动写入原生配置，确认同步才应用。关闭全部供应商可撤回模型字段，保留官方 OAuth 与客户端默认值。

等待任务结束，从托盘退出旧版，再完整解压新版运行 ASS.exe；数据目录不变。本次没有重启生产客户端或修改其凭据。

新客户端协议适配并未因本次布局重整而被标为完成；当前发布支持的接入仍为 Codex、Claude Code、OpenCode、pi、DSH。验证范围见 [验证记录](https://github.com/CaT-Hode/ASS-AI-Switching-Servant/blob/main/docs/VALIDATION.md)。
