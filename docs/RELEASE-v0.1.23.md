# ASS v0.1.23 · 配置与文案收口

- Codex 新接入不再生成旧路由工具风格的兼容 provider，只写 `ass_router`；仍会只读识别旧标记并拒绝竞争覆盖。
- OpenCode 本机缓存与 DSH 内置目录不再显示“未联网验证”等重复状态文案，真实连接状态继续由模型右侧闪电表示。
- Kimi 官方账户说明与已经实现的原生登录、加密账户历史及切换能力保持一致。
- 清理退役客户端残留的用量名称和 README 过时客户端数量；Antigravity 仍不进入产品支持面。

这是 v0.1.22 的小型修正版，不改变数据目录、供应商配置或原生客户端凭据。退出旧版 ASS，完整解压 Windows x64 ZIP 后运行 `ASS.exe`。
