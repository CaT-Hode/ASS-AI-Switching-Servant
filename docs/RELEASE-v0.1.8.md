## 升级

数据目录仍为 `%APPDATA%\AI Switch Servant`，无需重新导入。等待当前客户端任务结束，再从旧版托盘安全退出并启动新版；没有替你中断正在运行的客户端。ZIP 为未签名 Windows x64 便携版，请完整解压并核对 SHA256SUMS.txt。
