# ASS v0.1.11

- 模型行改为检测、详情、删除三个图标按钮，提供悬停提示，不再经过下拉菜单。
- 详细设置与能力详情合并为同一右侧窗口。配置和能力检测可直接展开，折叠时保留未保存草稿；检测明确使用已保存的模型配置。
- 删除确认改为紧邻垃圾桶按钮的小窗口，仅显示模型、警告、取消和确定，不再使用系统弹窗。取消、Esc、点击外部只关闭此确认，不提交删除。
- 删除失败保留确认窗并展示原因，支持重试。修复字段顺序不同导致的错误冲突判定，保留真正的并发修改保护及配置回滚。
- 验证点击窗外空白逐级返回：详情 → 模型列表 → 供应商卡片。拖选文本到窗外不关闭；嵌套确认窗的 Esc 不再向父弹窗传播。

## 验证

- 142 项核心测试通过，包含删除持久化、字段顺序变化、过期配置拒绝与写入失败回滚。
- Playwright 驱动隔离 Electron 窗口；1100 / 1380 / 1536 桌面宽度检查、减少动态效果、图标入口、展开草稿保留、能力检测、邻近确认、取消与失败重试通过。
- 删除后重新启动隔离应用，确认模型未恢复、其他模型和凭据未变。页面身份、非空内容、无框架错误层、控制台与截图检查通过。
- 测试使用合成账户和上游响应，没有删除真实模型、改写真实账户或停止用户的 harness 任务。

## 升级

完整解压 Windows x64 ZIP 后启动 ASS.exe，沿用现有用户数据目录。若旧版本仍在托盘运行，请等任务结束后退出旧版再打开新版；仅关闭主窗口不会退出托盘进程。本版没有重复实测全部上游 API 或 OAuth 登录。
