# ASS v0.1.6 · 红环图标

- Logo 中央的蓝色实心圆改为红色空心圆环，中心保持透明，沿用蓝色花瓣造型。
- Windows 图标裁去多余透明留白并居中，主体占比由约 70% 调整为约 94%，在相同系统图标尺寸下更醒目。
- 统一可执行文件、窗口与托盘图标，并为 16–256 px 的图标导出加入布局回归测试。

本版只调整品牌素材与图标导出，不变更账户、路由或持久化配置。数据仍使用 `%APPDATA%\AI Switch Servant`，无需重新导入。

## 升级

等待当前任务结束，从旧版托盘退出 ASS，再运行完整解压的新版 `ASS.exe`。经 ASS 路由的客户端需重新启动以取得新的本地令牌。此版本是未签名 Windows x64 预览版，请核对 SHA256SUMS.txt。
