# ASS reliability fixes — 2026-10-02

本轮保留原有未提交修改、无关配置和历史数据；没有提交、推送、安装或发布。复现及回归使用临时目录、合成记录、内存上游响应和本机 HTTP 路由，不使用真实账户凭据或历史文件。

## 复现

先添加测试，再修改生产代码。原代码下，新增后端测试 14 项均失败；真实 React renderer 初始 7 项中 6 项失败，关闭面板后收到失败回复的控制用例正常通过。失败分别对应保存后内存污染、原生目录误判、限制不一致、旧名称覆盖、退役投影重吸收、HTTP 200 任务失败误报、图标白名单以及旧用量覆盖。

第 8、9 项通过 esbuild 编译当前 React 组件，在独立 Electron BrowserWindow 中挂载真实 React DOM，以 Playwright 操作按钮、输入框和分页。使用受控异步回复检查页面内容；不是源码状态回放。测试配置与浏览器 profile 均在临时目录，HTTP/HTTPS 网络访问被阻断，没有加载生产 Electron 主进程或生产 IPC。

## 修复与回归范围

| 项目 | 修复 | 最小回归覆盖 |
| --- | --- | --- |
| 1. 删除供应商回滚 | `Store.removeProvider` 原子替换内存状态，保存失败恢复供应商及两个排除列表；IPC 调用该方法 | 加密失败、目录写入失败、失败后其他编辑、成功删除、重复删除 |
| 2. 普通 ID / 原生类型 | 优先解析实际保存的供应商；只有没有对应供应商且匹配明确客户端类型时才读取原生目录；额度刷新采用相同规则 | 导入 `native-codex` 后读取 API 目录、缓存重读、真实原生类型、未知类型拒绝 |
| 3. 统一限制 | 创建、模型编辑、合并导入和导出共用 100 个供应商、每供应商 10000 个模型、5 MiB UTF-8 配置上限；预算使用实际带缩进的可导出格式，包括密钥；界面和命令行导入采用同一个文件大小检查 | 数量边界、合并越界、超大密钥、中文字节、含密钥回导、重复导入、模型编辑越界；失败保留原状态 |
| 4. 原生项目改名 | 发现的有效原生项目名称更新已保存同步名称，列表及元数据搜索使用新名称；元数据暂时损坏时保留最后可用名称 | 启用同步后的原生改名、重复刷新、新旧搜索词、损坏元数据 |
| 5. retired 投影 | 同步扫描继续跳过旧 retired 身份；列表与同步只豁免当前已归属的投影路径，保留对不同路径旧副本的屏蔽；筛选在副本择优之前执行 | 关闭/开启、旧文件重新出现、相同 ID 重建、不同路径且更晚 mtime 的旧副本、重复刷新、释放失败、重复关闭 |
| 6. 请求日志 | JSON 与 SSE 都识别失败任务状态；`httpStatus/httpOk` 与 `taskOk/ok` 分开记录；页面显示“任务失败 · HTTP 200” | Codex 与客户端直通、JSON 与 SSE、HTTP 200 失败任务重复调用、正常完成、HTTP 503；原有无效/截断流用例保留 |
| 7. 本地清理图标 | `resources/ass.ico` 加入已知文件白名单，作为旧包可缺少的可选资源，其他未知文件仍阻止清理 | 含自家图标的旧包清理、重复部署、未知资源保留；全部操作针对假包 |
| 8. 正文分页 | 项目对话与保留副本列表自动选中另一会话时先重置正文偏移，避免用旧偏移请求短会话 | 两个真实 renderer 流程：长会话旧页→短会话、往返翻页、列表请求失败后恢复 |
| 9. 迟到回复 | 恢复面板用请求代次屏蔽关闭、重新打开或卸载前的旧回复；模型默认值请求在用户编辑或卸载时失效，迟到错误也不展示 | 关闭后恢复成功/失败、迟到列表回复、正常恢复及重复恢复、旧默认值成功/失败、随后新请求正常应用 |
| 补充：用量副本 | 同一消息按消息时间、文件版本时间、稳定兜底顺序选择；文件枚举顺序不参与决定。缓存签名更新，锁定文件仍可保留旧缓存 | 新旧副本调换文件名、缓存重扫、相同消息时间且新版本统计减少，均选择新版本 |

新增 24 项回归，分布于 `tests/reliability-regressions.test.cjs`、`tests/renderer-races.test.cjs`，以及项目同步、本地清理、用量统计的现有测试文件。第 8、9 项共 10 项真实 renderer 测试。
