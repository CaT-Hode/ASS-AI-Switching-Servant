# ASS v0.1.16

- 本周按小时：热力图每天 24 格（4 列），Token 趋势每柱一小时，悬停或键盘聚焦可查看具体区间。
- 本月每 4 小时汇总：每天 6 格（1 列），Token 趋势每柱 4 小时。本周 / 本月每列 6 格，先从上到下、再从左到右排列；未来格留空。
- 年视图保持不变：仍是近 365 天日格热力图和逐日 Token 趋势，不改为按周或按月汇总。
- DSH 日账本单列为“仅按日记录”，可展开每日明细；计入总量与分类，但不虚构小时分布。
- 用量加密缓存升级并自动重建小时元数据，时区变更后重读；视图选择继续跨重启保存。

## 升级

完整解压 ZIP 后运行 ASS.exe，沿用原有 ASS 数据。若旧版仍在托盘，请在任务空闲时退出旧版再启动新版；不会强制结束正在运行的客户端。

本版不修改供应商、OAuth 或客户端接入配置。仅调整本地用量读取与展示，未进行付费模型请求。数据范围见[用量总览](https://github.com/CaT-Hode/ASS-AI-Switching-Servant/blob/main/docs/USAGE-OVERVIEW.md)。
