# ASS v0.1.13

- 模型连接测试完成后，闪电改为实心：绿色表示成功，红色表示失败；未测试的模型保持空心。
- 悬停时保留测试结果颜色；测试过程中仍显示转圈，原有结果提示和重新检测操作不变。
- 供应商模型列表与连接诊断页面使用相同状态。取消首次测试不产生完成标记，取消重新测试则保留上次结果。

## 验证与边界

- 148 项核心测试、生产构建及隔离 Electron 的账户 / 模型和可靠性回归通过。
- 使用合成上游响应检查成功、失败、未测试、运行中及取消状态，并确认关闭 / 重开列表和刷新界面后显示一致；没有请求用户的真实模型，也没有修改其账户或路由配置。
- 测试结果沿用当前应用进程中的诊断记录，本版不增加跨应用重启的诊断历史保存。

## 升级

完整解压 Windows x64 ZIP 后启动 ASS.exe，继续使用原有 ASS 数据。若旧版仍在托盘运行，请先等任务结束，再退出旧版并打开新版。
