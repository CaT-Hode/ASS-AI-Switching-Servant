# ASS v0.1.27

## 重做图标交互

- 将 47 种操作图标改成独立的悬停、按下、移开三段动效。设置滑块、桶盖、文件夹等悬停后保持清晰姿态；移开从当前画面收回。
- 心电线有连续扫描轨迹与光点，屏幕有播放进度和点击后的动态内容；网格依次点亮，终端输入、网络传输和闪电充能分别使用各自的节奏。过程动画只在鼠标停留时播放。
- 点击不再仅加速悬停动画：刷新完成一圈、钥匙转动、箭头穿过边界、垃圾桶落纸等具有独立反馈。快速重复点击不重置半途的动作，实际操作无需等待动画。
- 修复供应商卡片中按钮外的图标没有触发动效的问题；补上客户端、供应商及接入列表中的品牌反馈，保留品牌图形本身。
- 移开、拖动、键盘操作、窗口失焦/隐藏、按钮禁用和元素被移除时均收回或停止动画，避免后台持续播放。

## Logo

- 保留八片蓝色花瓣与加粗红色空心圆，降低高光亮度，改用更浓的蓝色和红色渐变。
- 应用内、关于页、README、任务栏和托盘统一使用紧边界导出，减少画布留白。
- 已经紧边界的方形原图不再因固定留白比例而无法导出。

## 验证

- 420 项自动测试通过，涵盖动效状态、连续输入、禁用/移除清理，以及紧边界图标导出。
- 隔离的 Windows 打包窗口检查实际侧栏、客户端品牌、供应商卡片与模型操作；不操作真实账户、模型服务或客户端任务。
