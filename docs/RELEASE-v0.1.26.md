# ASS v0.1.26

## 图标与主题

- 47 种操作图标分别设计动效：诊断沿心电线传递光点、客户端屏幕短暂播放、滑块移动、垃圾桶掀盖、导入导出箭头流动等。品牌标志、账户数据和静态提示不循环闪动。
- 悬停播放一次，点击立即响应；快速连续触发沿用正在播放的进度，不从第一帧反复跳起。保留加载状态，键盘操作不触发装饰动画，并遵循系统减少动态效果设置。
- 主题胶囊按落点选择：左侧浅色、中间自动、右侧深色。拖动保持跟手、可随时反向，Esc 可取消；三档选择继续持久化。
- 深色月亮增加 24 秒缓慢月食周期，自动模式增加晨昏光晕与水面微光；三种模式均有错峰扩散的三层波纹。拖动、模式过渡和窗口隐藏时暂停闲置动画。

## 布局与品牌

- 主题切换移到左栏最底部，取消左栏独立“检查更新”入口；版本号移到顶部 ASS 标题旁，点击仍可进入关于页。
- “开机启动”放入“关于 ASS”，与“自动检查更新”使用相同开关样式，沿用 Windows 登录启动及持久化设置。
- Logo 改为八片更饱满的蓝色花瓣，中央红色空心圆更大、更粗，使用与花瓣一致的柔和渐变。同步更新窗口、托盘、可执行文件和快捷方式图标。

## 验证边界

- 覆盖图标动效部件、重复输入、禁用控件、减少动态效果、主题落点和拖拽回弹的测试。
- 在隔离的 Electron 窗口检查主题点击/反向拖拽/取消、月食与波纹、深浅配色、删除确认和关于页布局。开机启动测试模拟操作系统写入，不改变本机开机启动偏好。
- 本次不修改真实账户、API 密钥、客户端接入和运行中的 Codex/DSH。

退出旧 ASS 后打开新版本即可；正在处理任务时不要中断路由服务。
